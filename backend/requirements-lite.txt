# What this drops vs. requirements.txt, and why:
#   • torch / torchvision / torchaudio  — ~2.5GB install, GBs of RAM to
#     import and run. Disables the AI Models module (autoencoder/
#     transformer/LSTM/TCN). Everything else still works.
#   • asyncpg / psycopg2-binary          — Postgres drivers; SQLite
#     (aiosqlite) is used instead, no server needed.
#   • redis / celery[redis] real broker  — fakeredis + Celery eager
#     mode replace them; no Redis server needed.
#   • tsfresh, shap, lime                — heavy, spawn many worker
#     processes; feature_engine still works via RF/MI/F-test ranking.
#   • hdbscan                            — needs a C compiler on
#     Windows; KMeans/DTW clustering in pattern_discovery is unaffected.
#   • weasyprint                         — needs system Cairo/Pango
#     libs, painful on Windows; reportlab alone still produces PDFs.
#   • boto3 / aioboto3                   — S3 SDK; local disk storage
#     is used instead in desktop mode.
#
# Everything below still gives you: preprocessing, cycle detection
# (FFT/Lomb-Scargle/wavelet/ACF/Hilbert/Hurst), pattern discovery
# (KMeans/DTW/matrix-profile/HMM regimes), planetary correlations,
# 1000+ features (minus SHAP explainability), historical analogs,
# and stability testing.
